# Edit page lifecycle

Leaving Edit checkpoints the latest modified workspace, cancels obsolete deferred
restoration, releases native sizing/background presentation, and exposes native
Resolve for the destination page. Edit sessions/groups retain their content,
frames, tabs, pinning, hidden doors and independent metric scale preferences.
Existing per-session page visibility hides those surfaces without docking them.
Returning Edit resumes those retained surfaces, footer attachment and background
policy. It does not reload the selected saved preset. Startup restoration still
uses the persisted latest view through the existing workspace contract.

The lifecycle coordinator watches the actual Edit page's Qt Show/Hide events.
Repeated discovery does not restore twice; generation checks cancel superseded
rapid page returns and shutdown callbacks. Hidden fixture coverage passes.
Actual Resolve page transitions and GPU/viewer contents remain live acceptance.
