# Complete native footer

fix/macos-complete-native-footer supersedes the page-button-only primary strip.
The primary custom surface receives Resolve's original complete footer through a
reversible bottom-band lease. Home, Project Settings, logo and native status controls
remain their original widgets and signals. Native main keeps it while native editing
content remains there. Unpinning or returning to native restores the original slot.
Secondary pinned surfaces use native-painted button proxies, including Home and
Project Settings; those copies do not replicate every optional status widget.

The hidden navigation suite passes exact native ownership, original Home/Settings
signals, hide/show, primary transfer, narrow secondary reachability, restoration and
native pixel rendering at 1x/2x. Restart fixture expectations now follow actual native
footer ownership; compilation passes, full displayed restart testing remains pending.
No install or live acceptance is claimed.
