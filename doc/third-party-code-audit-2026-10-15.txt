Unbound third-party code audit - GammaRay
2026-10-15

Scope
-----
Reviewed the 23 C++ implementation/header files under src, root/platform/core
CMake definitions, release dependency manifests, tracked GammaRay references,
and repository history back to the initial import (ddfab07). Compared source
blocks against KDAB/GammaRay upstream commit
1ae8a5749850cc6f77f34cfa60cbc29bdbbda786.

Findings
--------
1. The launcher compiles launcher.cpp plus generated Windows resources.
   The helper compiles controller.cpp, bootstrap.cpp and windowplacement.cpp,
   with Unbound's shared headers. No GammaRay target, header or library is used.
2. Binary import auditing lists Qt5Core/Gui/Widgets, Windows system APIs and the
   MSVC runtime. Neither executable imports GammaRay or its probe.
3. Source review found Unbound-specific pane transfer, decoration, persistence,
   native window integration and Resolve widget discovery implementations.
   No KDAB copyright, GammaRay namespaces/includes or GPL implementation files
   occur in these sources. Sources carry Unbound's MIT identifiers.
4. Upstream comparison found no identical consecutive six-line implementation
   blocks containing at least 150 non-comment characters across 1,212 upstream
   C++ implementation/header files. This supplements source/build review; it
   cannot by itself rule out heavily modified copying or establish authorship.
5. History begins with a standalone Unbound import. The two GammaRay license
   files and NOTICE arrived with that import, but no GammaRay build targets or
   source implementation were imported with them. The project owner confirms
   GammaRay was used to inspect Resolve's widget hierarchy.
6. gammarayFloating and placeholder object names were historical identifiers,
   not references to GammaRay implementation. They are now Unbound identifiers.

Conclusion and cleanup
----------------------
No GammaRay implementation or runtime dependency was identified in shipped
Unbound. On the reviewed evidence and the owner's provenance statement, the
GammaRay notices in the source/release package were stale and have been removed.
This audit covers GammaRay; it is not a general audit of Qt or other components.

Removed src/GammaRay-LICENSE.txt, src/GammaRay-GPL-2.0-or-later.txt and the NOTICE
file that referenced only those files. Removed the README link to NOTICE.
Renamed legacy floating-host/placeholder identifiers in production and tests,
including the audition bridge and inspector diagnostic lookup.

Deliberately retained
---------------------
- tools/gammaray/ and its capture documentation: an ignored, separately packaged
  developer tool. Its own upstream notices have not been altered.
- Actual historical references to using GammaRay during investigation.
- gammaray_probe.dll detection in launchers: a compatibility check that refuses
  simultaneous attachment. This inspects a module name; it does not load, link
  or distribute GammaRay code.
